## Hard rules (from the user, 2026-10-20)

1. **No git writes.** Never `git commit`, `push`, `merge`, `rebase`, `stash`, `reset`, `checkout`/`switch`, `clean`, or `worktree`. Leave every change uncommitted. Read-only git (`status`, `diff`, `log`, `show`) is fine.
2. **No questions.** Decide with the recommended default (M-items in `docs/plan/01` §3: M-06 = Guava `InternetDomainName.topPrivateDomain()`, M-07 = 5 min, M-08 = English only) and record each decision in `docs/plan/01` §3 under a dated "Answers" paragraph.
3. **Laptop overheats — keep load low.**
   - Only one Maven build at a time. While developing run focused tests (`-Dtest=...` / `-Dit.test=...`); run the FULL `backend/mvnw -B -f backend/pom.xml verify` at the end of the phase (re-run only if you changed code afterwards).
   - Prefer in-JVM/embedded test infrastructure (e.g. spring-kafka-test embedded KRaft broker, JDK `HttpServer` stubs) over extra containers. MySQL stays on the shared Testcontainers container in `support/IntegrationTest`.
   - The docker compose stack is stopped. Start it only for the phase's short live checks, then `docker compose stop`.
4. **Secrets stay absent until after P13:** Google client ID/secret, `ADMIN_EMAILS`, SMTP, `CLOUDINARY_URL`, `GROQ_API_KEYS`. Code must degrade gracefully when one is blank (skip + log with no PII; never crash startup or the request). Do **not** try live checks that need them; record each such check in `docs/plan/05` §7 as `| date | phase | check | No | — | pending secrets |`. Locally generated values exist in `.env` for DB passwords, `TEXT_AES_KEY_BASE64`, `INDICATOR_HMAC_PEPPER` — never print them.
5. **Simple, production-grade, no bugs.** Follow `CLAUDE.md` (security invariants, D-27 logging, ProblemDetails, IDOR 404 vs role 403, If-Match/409, Flyway one DDL change per file, never edit an applied migration). Keep designs basic-to-medium and explainable.

## Engineering conventions already in the codebase

- Strict TDD: write the test, watch it fail for the right reason, implement, watch it pass. Names `method_condition_expected`. Fake letters/data only.
- Integration tests extend `com.offershield.support.IntegrationTest` (shared MySQL 8.4). State-changing requests use `support.RealCsrf.xsrf(mockMvc)` — **never** spring-security-test `csrf()` (it poisons the shared context). Principals via `support.TestPrincipals.signedIn(userId, role)`. GreenMail via `support.MailIntegrationTest`; thread-safe log capture via `support.LogCapture`.
- Feature packages own their tables and expose services; other features never use another feature's repository. Controllers → services → repositories; DTO records; never return entities.
- Errors: subclasses of `common/web/ApiException` (`NotFoundException`, `ConflictException`, `UnprocessableException`, `BadRequestException`, `ForbiddenException`, `PreconditionRequiredException`); `IfMatch` helper for versions; `ProblemResponseWriter` for filters.
- Users: `auth.UserDirectory` (`findContact`, `findContacts`, `findTpoCollegeId`), `auth.RoleLookup`, `CurrentUser`, `@AuthenticationPrincipal AppOidcUser`. Colleges: `college.CollegeService`. Memberships: `membership.MembershipService`. Audit: `common.audit.AuditLogService.record(actorId, action, targetId)`. Email: publish `notification.EmailRequested(to, subject, body)` inside the transaction; it is sent async after commit.
- Next free Flyway version: run `ls backend/src/main/resources/db/migration` (V1–V8 exist at the start of P5).
- Frontend: Angular 22 zoneless/signals in `frontend/`; tests `cd frontend && npx ng test --watch=false`; build `npx ng build`.

3. Each finished task in `docs/plan/04` gets `- **Status:** ✅ Done <date> on \`phase/p05-p13\` (uncommitted; evidence in 05 §7)`.
4. Self-review the phase diff against the phase spec, `CLAUDE.md` invariants and D-27 before reporting.
5. Report: files changed, `Tests run:` lines, decisions taken, anything pending (secrets) or deferred.
